## Specification Summary

1. **Namespace**: `aios.session.*` tools over MCP JSON-RPC 2.0 stdio transport (ADR-0035 §D-2).
2. **Tool Manifest**:
   - `aios.session.validate`: Syntactic and invariant validation for session IDs, usernames, or specs.
   - `aios.session.list`: Querying sessions with filtering and bounded pagination limit ($1 \le n \le 10,000$).
   - `aios.session.get`: Inspecting session status and spec by session ID.
   - `aios.session.action`: Executing lifecycle transitions (`authenticate`, `activate`, `lock`, `unlock`, `terminate`) with seat arbitration and optional audit reason.
   - `aios.session.create`: Bootstrapping new user or autonomous AI agent sessions into the store.
3. **Hardening**: 1 MiB spec payload ceiling, $\le 1024$-byte path bound with control character rejection, $\le 64$-char session ID bound.
4. **Audit Effects**: Every execution logged to SQLite WAL ring buffer (`audit.db`) with SHA-256 hash chaining.
