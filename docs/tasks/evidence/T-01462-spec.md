## 1. Specification Contract: `UserSessionSecurityPolicy`

```rust
use std::collections::BTreeMap;
use std::path::Path;
use serde::{Deserialize, Serialize};
use crate::session::{SessionClass, SessionState, SessionType, UserSessionSpec, UserSessionStore};

/// Maximum allowable size for a policy configuration file (64 KiB).
pub const MAX_POLICY_FILE_BYTES: u64 = 65_536;

/// Enforcement mode for user session security policy.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum SessionPolicyMode {
    Enforcing,
    Audit,
    Permissive,
}

/// Core security policy defining mandatory constraints on user and agent sessions.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct UserSessionSecurityPolicy {
    pub mode: SessionPolicyMode,
    pub disallow_root: bool,
    pub allowed_root_users: Vec<String>,
    pub allowed_greeter_users: Vec<String>,
    pub allowed_session_types: Vec<SessionType>,
    pub allow_remote_seat0: bool,
    pub disallowed_env_vars: Vec<String>,
    pub max_env_vars: usize,
    pub max_sessions_per_user: usize,
    pub max_total_sessions: usize,
    pub require_agent_sandboxed: bool,
}

/// Specific security violation encountered during session evaluation.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct SessionPolicyViolation {
    pub rule_id: String,
    pub session_id: String,
    pub description: String,
    pub fatal: bool,
}

/// Comprehensive policy evaluation report for a session specification.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct SessionPolicyVerdict {
    pub session_id: String,
    pub allowed: bool,
    pub mode: SessionPolicyMode,
    pub violations: Vec<SessionPolicyViolation>,
    pub evaluated_at: String,
}
```

## 2. Invariant Specifications (`SSP1..SSP7`)

- **SSP1 (Identity & Privilege Containment)**:
  - If `disallow_root == true`, rejecting any session with `uid == 0` unless `username` is in `allowed_root_users`.
  - Sessions of class `Greeter` must have `uid < 1000` or `username` matching an entry in `allowed_greeter_users` (default: `["lightdm", "gdm", "greeter", "sddm"]`).
- **SSP2 (Session Type & Class Gating)**:
  - `spec.session_type` must be in `allowed_session_types`.
  - If `spec.session_class == SessionClass::Agent`, `spec.session_type` must be `SessionType::AiAgent`.
  - If `spec.session_class == SessionClass::Greeter`, `spec.display` must be present and `spec.remote_host` must be `None`.
- **SSP3 (Seat & Display Hardware Protection)**:
  - If `spec.remote_host.is_some()`, `spec.seat == "seat0"` is forbidden unless `allow_remote_seat0 == true`.
  - If `spec.vtnr` is present, it must satisfy $1 \le \text{vtnr} \le 64$.
  - If `spec.display` is present, it must not exceed 32 bytes and must contain no ASCII control characters.
- **SSP4 (Environment Sanitization & Limits)**:
  - Disallowed environment variable names: `["LD_PRELOAD", "LD_LIBRARY_PATH", "IFS", "NODE_OPTIONS", "PYTHONPATH", "RUBYOPT", "PERL5OPT"]`.
  - Total environment entries in `spec.environment` must not exceed `max_env_vars` (default: 256).
- **SSP5 (Concurrency & Store Quotas)**:
  - `max_sessions_per_user`: bounded to $[1 \dots 128]$ (default: 32).
  - `max_total_sessions`: bounded to $[10 \dots 10,000]$ (default: 1,024).
- **SSP6 (Agent Execution Sandboxing)**:
  - When `require_agent_sandboxed == true`, sessions of type `AiAgent` or class `Agent` must run with unprivileged UID ($\ge 1000$).
- **SSP7 (Policy Modes & Fail-Closed Enforcement)**:
  - `Enforcing`: Any fatal violation sets `allowed = false`.
  - `Audit`: Violations are reported, but `allowed = true` is granted with audit emission.
  - `Permissive`: Evaluates clean without blocking.
  - Configuration file ingestion strictly stream-capped to $64\text{ KiB}$ (`MAX_POLICY_FILE_BYTES`).

## 3. Existing Interfaces Reused vs New Interfaces

- **Reused**:
  - `crate::session::{SessionClass, SessionScope, SessionState, SessionType, UserSessionSpec, UserSessionStore}`.
  - `crate::pep::{Capability, evaluate_access}` for agent capability checking.
- **New (AIOS-Specific)**:
  - `SessionPolicyMode`: Enforcing / Audit / Permissive tri-state enum.
  - `UserSessionSecurityPolicy`: Evaluation configuration with default constants.
  - `SessionPolicyViolation` & `SessionPolicyVerdict`: Structured telemetry report.
  - `evaluate_spec(&self, spec: &UserSessionSpec) -> SessionPolicyVerdict`.
  - `evaluate_store(&self, store: &UserSessionStore) -> Vec<SessionPolicyVerdict>`.
  - `from_file<P: AsRef<Path>>(path: P) -> Result<Self, String>`.
