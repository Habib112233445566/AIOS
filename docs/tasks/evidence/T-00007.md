## Acceptance criteria

## What was written

`docs/RUNBOOK-AUDIT-RETENTION.md` covers the full retention surface:

- **rotate** — checkpoint the live ring into an archived JSONL segment
  (CLI: `aiosh audit rotate --keep N [--dry-run]`; MCP:
  `aios.audit.rotate` with `keep_rows`; `--grant` required).
- **verify --full** — replay live chain + archived segments from
  checkpoint head (CLI: `aiosh audit verify --full`; MCP:
  `aios.audit.verify {"full": true}`).
- **seen** — bloom-backed was-this-hash-ever-logged query (CLI:
  `aiosh audit seen <hash> [--exact]`; MCP: `aios.audit.seen`).
- **segments** — list archived rotation checkpoints.
- Copy-paste CLI + MCP examples for each operation, alarm tables,
  disaster-recovery scenarios (4), backup cadence, and cross-substrate
  parity notes (Rust / TS / Python share the same contract).
