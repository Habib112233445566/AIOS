# Specification: T-02102 (PEP Decision Engine / data model: Specification)

## 1. Overview & Data Model Scope
The PEP Decision Engine data model specifies the core types for policy evaluation across AIOS. It defines the formal structure of authorization requests, decision outcomes, obligations, and combining algorithms.

## 4. Invariant Verification
- `PEPDEC1`: `allowed` is true if and only if `effect == PepDecisionEffect::Permit`.
- `PEPDEC2`: Requests must pass input hygiene (`validate_request`).
- `PEPDEC3`: Combining algorithms produce deterministic outputs.
- `PEPDEC4`: Atomic decision records with obligations.
- `PEPDEC5`: Pure evaluation without external side effects.
- `PEPDEC6`: Serialized output conforms to JSON-RPC and Audit Ring schemas.
