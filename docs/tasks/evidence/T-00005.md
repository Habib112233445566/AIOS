**Completed:** 2026-08-21

## Acceptance criteria

## What was built

`tools/complete_task.py <task_id>` — mechanically enforces the NO-SKIP law:

- Validates `task_id == current next_task` (read from `TASK_STATE.json`).
- On success: moves the task into `completed`, appends one event to
  `COMPLETIONS.jsonl`, and increments `next_task` by exactly 1 — atomic
  via temp-file + rename (shared with `tools/task_ledger.py`).
- On out-of-order input: exits non-zero with a clear refusal and writes
  nothing.

The full data model (`tools/task_ledger.py`) adds `done/block/unblock/
skip/rebuild/check/status` subcommands and v1→v2 state migration
(documented in T-00012/13/14/15 evidence).
