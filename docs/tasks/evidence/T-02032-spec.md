# T-02032: Specification — Capability Model MCP/API Surface

See complete specification at [T-02032-mcp-api-surface-specification.md](file:///c:/Users/OBSESSION/Desktop/AIOS_MERGED/docs/tasks/evidence/T-02032-mcp-api-surface-specification.md).

- **Tools Defined**:
  1. `aios.capability.list`: Enumerate capabilities with optional subject or active filtering.
  2. `aios.capability.get`: Fetch capability metadata by ID.
  3. `aios.capability.issue`: Issue root capability (consequential).
  4. `aios.capability.attenuate`: Attenuate child capability (consequential).
  5. `aios.capability.revoke`: Cascade revoke capability and subtree (consequential).
  6. `aios.capability.check`: Fast permission check against registered capabilities.
  7. `aios.capability.prune`: Prune expired leaf capabilities (consequential).
- **Security & Envelopes**: Standard JSON envelope (`ok`, `tool`, data/error), PEP evaluation, and Audit Ring emission on every call.
