# T-01662: Specification

See full specification in [T-01662-security-policy-specification.md](./T-01662-security-policy-specification.md).
Key aspects specified:
- Invariants SP-KM1 through SP-KM6.
- Data structures: `KernelModulePolicyMode`, `KernelModuleSecurityPolicy`, `KernelModulePolicyViolation`, `KernelModulePolicyVerdict`.
- Evaluator methods: `validate`, `evaluate_directive`, `evaluate_autoload`, `evaluate_store`, `from_file`, `from_source`.
- Error and audit semantics for Enforcing, Audit, and Permissive modes.
