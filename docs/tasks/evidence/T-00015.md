## Bugs found & fixed by the tests

1. Default-argument binding: mutation functions captured `STATE_PATH` etc.
   at def-time, breaking path override for tests/alternate roots. Fixed:
   constants resolved at call time.
2. `next_task=None` formatting crash: NO-SKIP error message used
   `f"T-{None:05d}"` → uncaught `TypeError`. Fixed with `_fmt_task()`
   helper.
3. Legacy CLI positional mode was unreachable (argparse subparsers reject
   bare numeric args). Fixed: numeric argv handled before argparse.

Both unit tests added to `ci/run_all_smokes.sh`.
